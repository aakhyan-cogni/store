# API information and generation command

Status: ready-for-agent
Type: task
Blocked by: 02, 04, 05, 06

## Goal

Add configurable API information plus a command that discovers, generates, validates, and writes the canonical `openapi.json` without application startup.

## Acceptance criteria

- Title, semantic version, description, server URLs, and output path are configurable with useful project defaults.
- Generation runs after TypeScript compilation without binding a port, initializing Postgres, or requiring application secrets.
- A check mode validates the generated bytes and exits nonzero for invalid or stale output.
- Output ordering and bytes are deterministic.
- Command-level tests cover success, a selected output path, and failure.
